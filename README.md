- OpenAI

---

## Project Goal

Build an AI-powered Business Intelligence platform that answers natural language business questions using a governed semantic layer instead of generating unsafe SQL.

The platform enables business users to ask questions in natural language and receive accurate, explainable, and secure analytics insights through an AI agent connected with a semantic data layer.
